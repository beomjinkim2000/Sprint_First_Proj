**후처리·하이퍼파라미터 실험에서 얻은 기준**

후처리 실험은 단일 옵션으로 점수를 크게 올리기 위한 실험이라기보다, 모델 예측을 Kaggle 제출 형식에 안정적으로 맞추고 모델별 예측 분포를 확인하는 기준을 세운 과정. Ultralytics NMS, confidence threshold, IoU threshold, max detections, class-aware/class-agnostic NMS, bbox clamp, TTA를 비교하면서 후처리 조합만으로 일반화 성능을 크게 끌어올리기는 어렵다는 점을 확인

그래서 이후에는 학습 중 후처리 조건을 계속 흔들기보다, 좋은 checkpoint가 나온 뒤 F1 curve와 시각화를 통해 confidence threshold를 재확인하는 방식이 더 적절하다고 판단. 특히 해상도나 모델 구조가 바뀌어도 Kaggle 제출은 원본 이미지 좌표 기준이므로, 좌표 복원과 submission format 검증은 계속 유지해야 하는 안정화 장치로 볼 수 있다.

하이퍼파라미터 실험은 모델 크기, epoch, batch size, learning rate, weight decay가 학습 안정성과 일반화에 어떤 영향을 주는지 판단 기준을 만든 과정. Q4에서 epoch를 늘릴수록 validation 지표는 좋아 보였지만 Kaggle score는 떨어지는 구간이 확인, val_loss나 val mAP만으로 과적합을 완전히 판단하기 어렵다는 점을 확인. 따라서 최종 판단은 Kaggle score, loss 흐름, epoch별 변화, batch size에 따른 학습 흔들림을 같이 봐야 한다.

Q5 전략에도 연결. 해상도 실험은 단순히 img_size를 키우는 실험이 아니라, 알약 각인과 텍스트 정보를 더 잘 보존할 수 있는지 확인하는 실험. 대신 해상도가 커지면 batch size가 줄어 학습이 불안정해질 수 있으므로 learning rate를 낮춰 보정하는 전략이 필요. synth 실험은 epoch를 더 늘리는 방향이 아니라, 데이터 다양성 부족이라는 병목을 완화할 수 있는지 확인하는 실험으로 볼 수 있다.


결론
후처리 실험은 예측 결과를 안정적으로 제출 형식에 맞추는 기준을 세웠고, 

하이퍼파라미터 실험은 무조건 오래 학습하는 것보다 Kaggle score와 일반화 흐름을 보고 실험 방향을 정해야 한다는 기준을 세웠다.


> 기존 Q3 ep150 실험에서는 YOLO11x가 좋은 모델 선택지라는 것을 확인했다. 이후 Q5에서는 같은 계열의 모델을 더 높은 해상도로 확장했을 때 성능 개선 가능성이 있는지 확인했다. img1280 실험은 200 epoch 목표였지만 epoch94에서 best val mAP 0.9639를 기록한 뒤, 50 epoch 동안 개선이 없어 early stopping으로 종료 따라서 이 실험은 최종 성능 확정보다는, 고해상도 설정이 초반부터 높은 validation 성능에 도달할 수 있다는 가능성을 보여준 실험으로 해석
