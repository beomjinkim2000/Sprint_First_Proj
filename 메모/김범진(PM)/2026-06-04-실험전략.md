- **결과**: **0.721**

### Q4 — 과적합 진단 (ep150→700 스캔)
| epoch | Kaggle |
|---|---|
| 150 | 0.93817 |
| 200 | 0.94061 |
| **250** | **0.94325** ← 실질 최고점 |
| 600 | (val 0.973, 미제출) |
| 700 | **0.93593** ↓ 과적합 확정 |

**핵심 발견 — loss로는 과적합 안 잡힘:**
```
ep200부터 val mAP@50 = 1.0 고정 (val set 포화)
val_loss도 계속 내려가 보임 → 실제론 val을 암기하는 것
Kaggle test가 유일한 진짜 신호
```

| 지표 | 사용 가능? | 이유 |
|---|---|---|
| val_loss | ❌ | val 포화로 신호 없음 |
| val_mAP@50 | ❌ | ep200부터 1.0 고정 |
| val_mAP@0.5:0.95 | △ | 느리게 움직이긴 함 |
| **Kaggle score** | ✅ | 유일한 진짜 신호 |

**추가 발견 — train_loss oscillation:**  
batch=8이 작아서 gradient 방향이 들쭉날쭉. Phase 전환 시 LR 리셋으로 추가 spike.  
gradient accumulation(×4 → effective batch=32)으로 완화 가능.

**Q4 결론**: 최적 epoch = **250**. Q5·Q6 공통 기준값.

### Q5 — 현재 진행 중 (두 갈래 병렬 실험)

#### 실험A: 합성 데이터 (`feature/synth-aug-400ep`)
- **가설**: plateau = 기존 데이터 신호 소진 → 합성 데이터로 일반화 격차 해소
- **설정**: YOLO11x, 640px, batch=8, 400ep, early_stop 비활성화
- **합성 데이터**: GrabCut으로 알약 크롭 770개 → 배경 패치 390개 → 합성 3000장
  - 역빈도 가중치로 희귀 클래스 알약 자주 합성
  - val에는 넣지 않음 (train 다양성 전용)
- **상태**: 실행 중

#### 실험B: 고해상도 (`main`)
- **가설**: 원본 이미지 976×1280 → 640px 리사이즈 시 각인/텍스트 손실 → 1280px로 복원
- **설정**: YOLO11x, 1280px, batch=4, 1500ep, early_stop patience=50, delta=0.03
- **참고**: 1024px 사전 실험(Q5-highres)에서 val 0.972 확인했으나 Kaggle 미제출
- **상태**: 실행 중

## 3-Phase 학습 전략 (공통)

```
Phase 1 = 전체 × 0.2   → main: 300ep / feature: 80ep
Phase 2 = 전체 × 0.4   → main: 600ep / feature: 160ep
Phase 3 = 나머지 0.4   → main: 600ep / feature: 160ep
```

| Phase | 열린 레이어 | EMA | 목적 |
|---|---|---|---|
| Phase 1 | cv3 last Conv2d만 | OFF | 새 분류 레이어 수렴 먼저 |
| Phase 2 | Detect Head 전체 | **ON (새로 시작)** | bbox + 분류 동시 최적화 |
| Phase 3 | 전체 (backbone LR = head × 1/10) | **리셋** | 전체 fine-tune, pretrained 특징 보존 |

- `phase3_warmup_epochs: 5` — 갑작스런 전체 학습 불안정 방지
- `phase3_bn_frozen_epochs: 5` — Phase3 초반 BN eval 유지 (loss spike 방지)

## DataLoader 전략

### Iterative Stratification
- 56개 클래스 비율 동시 최적화 → val에 모든 클래스 보장
- random split은 희귀 클래스가 val에서 통째로 빠질 수 있음

### WeightedRandomSampler (inverse_freq)
- 클래스 등장 빈도 역수로 샘플 가중치 → 희귀 클래스 오버샘플링
- synth data 포함 시에도 작동 (annotations 합산 처리)
- Stratification은 분할, Sampler는 batch 구성 — 역할 다름
